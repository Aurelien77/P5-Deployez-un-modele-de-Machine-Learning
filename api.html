Prédire et enregistrer

Calcule la probabilité de départ, applique le seuil, puis enregistre le résultat. Une prédiction de 1 signifie un risque de départ.

Request Body schema: application/json
required
modele
required
string (Modele)

Nom du modèle chargé, par exemple top1.

required
object (Features)

Valeurs des colonnes du modèle.

seuil
number (Seuil)
Default: 0.37

Seuil au-dessus duquel l'employé est classé à risque.

Prenom (string) or Prenom (null) (Prenom)
Default: "John"

Prénom enregistré avec la prédiction.

Nom (string) or Nom (null) (Nom)
Default: "Doe"

Nom enregistré avec la prédiction.

Employe Id (integer) or Employe Id (null) (Employe Id)

Identifiant annuaire. Vide si les features sont saisies à la main.

Enregistrer une prédiction

Enregistre une prédiction déjà calculée. Sans employe_id, les features sont copiées dans details.

Request Body schema: application/json
required
Prenom (string) or Prenom (null) (Prenom)
Default: "John"

Prénom associé à la prédiction.

Nom (string) or Nom (null) (Nom)
Default: "Doe"

Nom associé à la prédiction.

modele_utilise
required
string (Modele Utilise)

Modèle qui a produit la prédiction.

probabilite_de_quitter
required
number (Probabilite De Quitter)

Probabilité de départ, entre 0 et 1.

prediction
required
integer (Prediction)

1 si le seuil est dépassé, sinon 0.

libelle_prediction
required
string (Libelle Prediction)

Libellé lisible, par exemple Quitte ou Reste.

seuil_applique
required
number (Seuil Applique)

Seuil utilisé pour trancher la prédiction.

object (Features)

Features de la saisie. Ignorées en base si employe_id est renseigné.

Employe Id (integer) or Employe Id (null) (Employe Id)

Employé lié. Doit exister dans employes_features si renseigné.
